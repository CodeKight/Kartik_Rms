# Restaurant Management System (RMS)

A complete web application built with Python and Django to handle the daily operations of a restaurant. This system makes it easy to manage food menus, organize item categories, and handle customer orders smoothly using secure, token-based authentication.

---

## 🚀 Key Features

* **Menu & Category Management:** Easily organize food items into distinct categories (like Appetizers, Mains, Desserts, or Drinks).
* **Order Processing API:** Handles the full workflow of an order from the moment a customer places it to when it is completed.
* **Token Authentication:** Secure login system using tokens. Only logged-in users with the right permissions can access the order system or modify the menu.
* **Custom User Setup:** Designed using a clean user structure to make sure authentication connects perfectly with restaurant staff profiles.

---

## 🛠️ Tools Used

* **Language:** Python
* **Web Framework:** Django and Django REST Framework (DRF)
* **API Documentation:** DRF Spectacular (creates a test web page for the backend links)
* **Database:**  PostgreSQL
